# Self-Assertion and Human Values Across National Contexts

An independent computational cultural psychology project examining Self-Assertion language and its associated human values in UN General Debate speeches (2016–2025).

The project uses a Knowledge-Guided Lexicon (KGL) to identify Self-Assertion-related language and a pretrained DeBERTa model to examine associated human values across 18 countries and nine selected regional pairs.

## Repository Contents

- `notebooks/` — Data processing, lexicon development, and analyses
- `data/` — Project datasets and intermediate outputs
- `outputs/figures/` — Figures illustrating the findings
- `METHODS_LOG.md` — Detailed documentation of methods and analytical decisions

## Environment

- Python 3.11.9
- Key libraries: pandas, NumPy, SciPy, Gensim, spaCy, scikit-learn, matplotlib, and Transformers
